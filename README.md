
# Terminal-Based Splitwise Simulator

A terminal-based group expense management application developed in Java, inspired by [Splitwise](https://www.splitwise.com/).

The application helps users manage shared expenses, split costs between group members, track debts, and settle balances within groups.

## ✨ Features

- **User Management:** User registration, login, input validation, and profile management.
- **Group Management:** Create groups, manage members, and organize shared expenses.
- **Expense Management:** Record expenses and split costs equally or unequally among group members.
- **Debt Calculation:** Automatically calculate debts and credits between users.
- **Settlement:** Manage and track expense settlements.
- **Multiple Currencies:** Support for different currencies and currency conversion.
- **Command-Line Interface:** Interactive terminal-based interface with command processing using Regular Expressions.

## 🛠️ Technologies and Concepts

- Java
- Object-Oriented Programming (OOP)
- Model-View-Controller (MVC)
- Java Collections
- Regular Expressions (Regex)
- Java Enums and Records

## 📁 Project Structure

The project follows the MVC (Model-View-Controller) architectural pattern to separate application logic, data management, and user interaction.

- **Model:** Handles application data and business logic.
- **View:** Manages terminal-based user interaction.
- **Controller:** Processes commands and coordinates application operations.

## 🚀 Getting Started

### Prerequisites

- Java Development Kit (JDK)

1. Clone the repository:

   ```bash

   ```

2. Open the project in your preferred Java IDE.
3. Build and run the main application class.
